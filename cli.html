Headless mode / CT v2.2.0.1

The command line interface.

The same engine that powers the desktop window runs without a GUI, which is useful for automation, CI installs, and verification. One entry point, eight options, and the game's own exit code back.

Quick start

Invocation.

Run the shaded jar with its entry point class. The jar is produced by ./mvnw package alongside the desktop distribution.

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine [options]

Build first if the jar is missing: ./mvnw package requires JDK 21 or later and produces target/ct-client-2.2.0.1.jar. See getting started.

Reference

Options.

Every option is optional; defaults come from the arguments themselves and from settings.properties.

OptionMeaningDefault
--version <id>Any version ID listed in Mojang's official version manifestLatest release
--game-dir <path>Game directorygame.directory from the settings, otherwise ~/.ct-client/game
--player <name>Offline profile name, 3 to 16 characters of letters, numbers, and underscoresCTPlayer
--memory-max <mb>Maximum heap size in megabytesmemory.maximumMb from the settings
--verifyRe-check every installed file against the official SHA-1 instead of trusting an existing installationoff
--install-onlyInstall and verify, then stopoff
--dry-runPrint the launch command and stopoff
--helpPrint usage and stopoff
Details

Behavior notes.

What headless mode does and does not do, and how it reports results.

  • Command line mode always uses an offline profile. Microsoft sign-in is only available in the desktop launcher.
  • An existing installation is reused. --verify forces a full re-check.
  • --memory-max also lowers the minimum heap when the configured minimum is larger, so the pair stays valid.
  • --dry-run prints the exact argument list without starting the game, including the resolved official Java runtime path.
  • The process waits for the game and exits with the game's exit code, so scripts can branch on it directly.
  • If an installation stops partway, re-run the same command. Verified files are kept, so the install resumes rather than restarting.

Reminder: offline profiles cannot join online-mode servers. For online play use the desktop launcher's Microsoft sign-in; see accounts.

Recipes

Common invocations.

Copy-paste commands covering the usual automation cases.

Install the latest release and stop

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --install-only

Launch with a named offline profile

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --player DevPlayer

Print the exact launch command without starting the game

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --dry-run

Verify a specific version and stop after installing

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --version 1.20.4 --verify --install-only

Print every option

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --help
