Getting Started

Build & Run

JDK 21 or later. No third-party Java dependencies.

bash
mkdir -p out
javac --release 21 -d out src/main/java/com/ct/client/CTClient.java
cp -R src/main/resources/. out/
java -cp out com.ct.client.CTClient
directory layout
docs/                         Architecture & release policy
src/main/java/                CT launcher code
src/main/resources/           Client brand assets
versions/CT vX.Y.Z/           Per-release notes, config, license

When adding a release, create a new versions/CT vX.Y.Z/ directory. Do not overwrite old release materials.

Policy

Version & IP boundary.

Minecraft, Mojang, Microsoft and their assets are not licensed by CT.

Version Rules

Directory name uses CT vMAJOR.MINOR.PATCH. Released versions are immutable — fixes create a new directory while keeping old audit materials.

Security Constraints

Default-deny untrusted manifests, unknown sources, path traversal, unverified updates. Never store or upload Minecraft/Microsoft passwords. Never bypass official authentication.

Distribution Boundary

Only CT-owned code, config, and assets are distributed. All third-party dependencies retain their license notices. No unlicensed game files in any package.

Pre-Release Checklist

Threat modeling, dependency scanning, code signing, privacy statement, and legal review must be completed before public release.
