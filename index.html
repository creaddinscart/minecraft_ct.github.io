In this release

A clear first step.

CT Loader establishes a native mod format and startup contract. It is an extensible base, not a claim of feature parity with established loaders.

01 / DISCOVER

Scan mod JARs

Read root-level ct.mod.json files from the configured game's mods/ directory.

02 / RESOLVE

Check dependencies

Reject duplicate IDs, missing dependencies, and cycles before any mod entrypoint runs.

03 / INITIALIZE

Call CT entrypoints

Initialize CT mods in dependency order, then hand control to Minecraft's official main class.

Compatibility boundary
Fabric, Forge, and NeoForge mods are not supported. Minecraft hooks and class transformation are future work.
