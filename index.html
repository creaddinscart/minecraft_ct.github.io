Why CT

Built to be exact.

Every file CT downloads is checked against the SHA-1 and size published in Mojang's metadata. Every launch argument is built from that same metadata, with no shell and no silent substitutions.

01 / VERSIONS

Any official version

Releases, snapshots, and legacy IDs from the live official manifest. The selector loads 900+ version IDs and stays editable.

02 / SECURITY

Verified downloads

SHA-1 and size checks, HTTPS-only sources, safe archive extraction, and resumable installs that keep verified files.

03 / MODS

CT Loader + Fabric detection

Drop CT mod JARs into the mods/ folder. Fabric mod JARs are detected and routed to the matching profile.

04 / ACCOUNTS

Microsoft or offline

OAuth device code sign-in for online play, or a one-click offline profile for development and single-player testing.

05 / CONTROL

GUI and command line

The same engine runs headless with --install-only, --dry-run, and full version selection for automation.

06 / INTERFACE

CT dark theme

A custom-drawn Swing interface: grouped settings cards, rounded console, animated progress bar, and branded header.

Requirement: JDK 21 or later to run CT. The Java runtime the game needs is downloaded by CT itself from Mojang's official runtime manifest.
