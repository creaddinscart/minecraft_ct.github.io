Configuration / local data

Your settings, your game directory.

CT stores non-secret preferences separately from game files. Access tokens are not written to the settings file.

Settings file

Settings are stored at ~/.ct-client/settings.properties. Missing keys use defaults; invalid numeric values fall back per setting.

KeyDefaultPurpose
microsoft.clientIdemptyAzure public client ID. CT_MICROSOFT_CLIENT_ID overrides a stored value when nonblank.
memory.minimumMb2048Minimum Minecraft heap, in megabytes.
memory.maximumMb4096Maximum Minecraft heap, in megabytes.
resolution.customfalseEnable custom game window dimensions.
resolution.width854Custom window width; minimum 320 when enabled.
resolution.height480Custom window height; minimum 240 when enabled.
offline.playerNameemptyLast selected desktop offline profile name.
java.executableemptyOptional Java executable override; empty uses the official installed runtime.
jvm.recommendedFlagstrueApply Mojang's recommended default-user JVM flags.
game.directory~/.ct-client/gameGame files, runtime, logs, and CT mods are stored here.

The minimum and maximum heaps must be between 1024 MB and 65536 MB, and maximum must be at least minimum. CLI --memory-max lowers the minimum too when required to keep the pair valid.

Game directory layout

~/.ct-client/
  settings.properties
  game/
    versions/<id>/<id>.json    Verified version metadata
    versions/<id>/<id>.jar     Verified Minecraft client
    versions/<id>/natives/     Native library directories
    libraries/                 Platform-matched libraries
    assets/indexes/             Asset index JSON
    assets/objects/             SHA-1-addressed asset objects
    assets/log_configs/         Official logging configuration
    runtimes/                   Official Java runtime files
    mods/                       CT mod JARs
    logs/ct-client-launch.log   Appended game output

Change the game directory in the desktop settings or use --game-dir in CLI mode. The CT mod directory is always <game directory>/mods.

Desktop settings behavior

The client ID and offline player name are persisted from the desktop UI. The selected game directory is saved when CT scans versions or installs a game. Memory, resolution, and Java executable launch values are currently read from settings.properties; edit that file and restart CT for those values to take effect.

Troubleshooting

SymptomWhat to check
Set your Microsoft application client ID in Settings first.Set microsoft.clientId or CT_MICROSOFT_CLIENT_ID.
This Microsoft account does not own Minecraft Java Edition.Sign in with an account that owns Java Edition.
This Microsoft account has no Xbox profile.Complete Xbox profile setup, then try Microsoft sign-in again.
Official metadata failed its SHA-1 verification.A proxy or mirror may have changed the file. CT refuses to continue with an unverified download.
Refusing a non-HTTPS download URL.CT accepts HTTPS sources only; do not weaken this check.
Unsupported launch value.The metadata requires a placeholder CT does not implement. The launch fails instead of silently dropping it.
Official Java runtime is missing its executable.Delete the incomplete runtimes/<component> directory and install again.
Installation stops partway.Run install again. Previously verified files are retained so installation can resume.
Private data

Settings contain no access token. The Microsoft client ID is public-client configuration, not a client secret.
