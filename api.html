Developer reference / Java 21

Public Java APIs.

CT exposes settings, accounts, installation, launch, rule evaluation, authentication, and CT mod entrypoint types from com.ct.client.

ClientSettings

Reads and writes non-secret preferences in ~/.ct-client/settings.properties. The constructor creates the file and application directory when needed and can throw IOException.

ClientSettings settings = new ClientSettings();
Path gameDirectory = settings.gameDirectory();
LaunchOptions options = settings.launchOptions();
settings.setOfflinePlayerName("DevPlayer");
  • applicationDirectory() returns normalized ~/.ct-client.
  • gameDirectory() and setGameDirectory(Path) get or set the game location.
  • launchOptions() and setLaunchOptions(LaunchOptions) manage memory, resolution, and flags.
  • Microsoft client ID, offline name, and optional Java executable have corresponding getters and setters.
  • Access tokens are not part of this settings API.

LaunchOptions

LaunchOptions options = new LaunchOptions(
    2048, 4096, false, 854, 480, false, true, "release");

The record fields are minimum/maximum heap MB, custom-resolution flag, width, height, demo flag, recommended JVM flags flag, and version type. Heap bounds are 1024-65536 MB. Custom resolution requires at least 320 by 240 pixels. LaunchOptions.defaults() returns 2048/4096 MB, 854x480, recommended flags enabled, and release version type. Invalid values throw IllegalArgumentException.

Account and authentication

Account offline = Account.offline("DevPlayer");
Account microsoft = new MicrosoftAuthenticator()
    .signIn(clientId, System.out::println);

Account.offline(String) accepts names matching [A-Za-z0-9_]{3,16} and derives a stable UUID. Account values expose the name, UUID, token, XUID, client ID, and user type used for launch. Never log or persist the access token.

MicrosoftAuthenticator.signIn(String, Consumer<String>) runs device-code authentication, opens the browser, reports status, validates a Java Edition profile, and returns an MSA account or throws an actionable IOException.

MinecraftInstaller

MinecraftInstaller installer = new MinecraftInstaller(Path.of("/games/ct"));
    MinecraftInstaller.VersionCatalog catalog = installer.versionCatalog();
MinecraftInstaller.Installation installed =
      installer.install(catalog.latestRelease(), System.out::println);
    MinecraftInstaller.Installation existing = installer.existing("1.20.4");
    List<String> profiles = installer.installedModLoaderProfiles();
    MinecraftInstaller.Installation loader =
      installer.existingModLoaderProfile("fabric-loader-...");

versionCatalog() returns every safe version ID from Mojang's official manifest and its latest release ID. install(version, status) resolves official metadata, downloads the client, libraries, native classifiers, assets, logging configuration, and official runtime, then extracts native libraries. existing(version) returns an installation from local files or null when required files are missing. installedModLoaderProfiles() lists detected Fabric, Forge, and NeoForge profiles. External loader files must be installed separately.

GameLauncher

GameLauncher launcher = new GameLauncher(installer.gameDirectory(), "2.2.0.1");
List<String> command = launcher.buildCommand(installed, account, options);
Process process = launcher.launch(installed, account, options, System.out::println);

buildCommand(...) returns the argument list and throws when launch metadata, placeholders, or classpath are invalid. launch(...) starts with the game directory as working directory, logs output to logs/ct-client-launch.log, forwards lines to the consumer, and returns the process.

RuleEvaluator

allows(JsonObject, Features) evaluates Mojang library and argument rules. The last matching rule wins; a rule-bearing entry with no matching rule is denied. operatingSystem() returns windows, osx, or linux; architecture() returns the raw JVM architecture. isArm() and is64Bit() expose architecture predicates.

Features contains demo-user, custom-resolution, quick-play support, and single-player, multiplayer, and Realms flags. Features.none() disables all features.

CT mod API

public final class ExampleMod implements CTMod {
    @Override
    public void onInitialize(CTModContext context) {
        context.log("Ready");
    }
}

CTModContext exposes mod metadata, game directory, mods directory, and scoped logging. The current API initializes code before Minecraft's main class and does not include game event or transformation hooks.
