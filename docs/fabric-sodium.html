Run Fabric mods with CT.

Fabric mods are not CT-native mods. CT hands them to Fabric Loader, which must be installed for the same Minecraft version and in the same game directory.

Install Fabric for CT

  1. 01Check the mod versionUse the Minecraft version named in the Fabric mod file. The reported Sodium file targets Minecraft 26.3, so install Fabric for 26.3.
  2. 02Get the official installerDownload Fabric Installer from fabricmc.net. Do not download a loader JAR from an unofficial mirror.
  3. 03Choose the Client profileOpen the installer, select the Client tab, choose Minecraft 26.3 and a compatible Fabric Loader version.
  4. 04Use CT's game directoryIn CT Settings, copy the exact Game directory path. Set the Fabric installer's Game Directory to that same path before installing.
  5. 05Install and refreshInstall the profile. In CT, click Refresh versions. The Fabric profile should appear under the same game directory.
  6. 06Place the mod JARPut the downloaded Sodium .jar directly in <game directory>/mods/. Do not unzip it or put it in a nested folder.
  7. 07Launch the matching versionSelect Minecraft 26.3 and launch. If there is exactly one matching Fabric profile, CT selects it automatically; if there are several, select the desired fabric-loader-…-26.3 profile.

Check the directory

CT's default directory is <user home>/.ct-client/game. The value shown in CT Settings is authoritative. A Fabric profile installed into the regular Minecraft launcher directory will not be found if CT is using its separate default directory.

<CT game directory>/
|-- mods/
|   `-- sodium-fabric-...-mc26.3.jar
`-- versions/
    `-- fabric-loader-...-26.3/
        `-- fabric-loader-...-26.3.json

Install any additional dependencies required by the specific mod, using versions compatible with both Minecraft and Fabric Loader.

If CT says no Fabric profile is installed

  1. Confirm the Fabric installer's Game Directory exactly matches CT Settings.
  2. Confirm the installed profile's parent Minecraft version is 26.3, not just a similarly named release.
  3. Click Refresh versions and look for a profile beginning with fabric-loader-.
  4. Confirm the Sodium JAR is directly inside that same directory's mods/ folder.
  5. If more than one matching profile is listed, select one explicitly before launching.

Compatibility: a Fabric profile does not make an incompatible mod compatible. Check the mod author's supported Minecraft and Fabric Loader versions before launching.

What CT installs

CT installs official Minecraft files and can launch installed loader profiles. It does not install Fabric Loader, Fabric API, Sodium, or other third-party mods. Fabric Loader runs Fabric mods; CT's own ct.mod.json format is separate.
