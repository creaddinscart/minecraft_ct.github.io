Trust / privacy / distribution

Know what runs and what is stored.

CT protects account tokens from persistence and verifies official downloads. CT mods are executable code and are not sandboxed.

Authentication and account data

  • Microsoft sign-in uses OAuth 2.0 device code flow, then Xbox Live, XSTS, and Minecraft Services exchanges.
  • CT checks the Minecraft profile endpoint to confirm the account owns Java Edition.
  • Passwords are entered at Microsoft's website, not into CT. Access tokens are held in memory for the current launcher session and are not written to the settings file.
  • CT redacts the access token from command output and appends game output to the local launch log.
  • The configured Microsoft application is a public client. Its client ID is not a client secret.

CLI mode only supports offline profiles. Offline accounts cannot join online-mode servers. The launcher does not bypass purchase or authentication checks.

Game download integrity

  • Official manifests and game files are acquired through HTTPS and official Mojang hosts.
  • Downloads are checked against published SHA-1 and file size. Invalid files are not installed.
  • Files are written to a temporary .part path and moved into place only after verification.
  • Metadata paths are checked to prevent writing outside installation directories. Non-HTTPS download URLs are rejected.
  • Transfers use HTTP/1.1 with up to four attempts and backoff. The official Java runtime is validated before its completion marker is written.

SHA-1 is used to match Mojang's published metadata integrity values; it is not a signature or proof that the source author is trusted.

Mod trust boundary

CT mod JARs are Java programs. They run in the user's process with the user's operating-system permissions. CT Loader does not sandbox, sign, or remotely review mods.

Only install mods you trust. A mod can read or change files available to your user account and can make network requests.

Third-party software and Minecraft

CT does not include Minecraft game files or official assets. Users obtain game files through authorized official channels and remain responsible for their Minecraft license and applicable terms. Third-party libraries, icons, fonts, services, and content have their own licenses and terms.
