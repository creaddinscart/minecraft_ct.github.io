Inside the ZIP

What each package contains.

The desktop ZIP is self-contained and source-free. Project source code stays in this repository, not in the release archive.

01 / APPLICATION

GUI JAR

The compiled CT Client desktop application, ready to run with a JDK.

02 / SCRIPTS

Launch scripts

Separate launch scripts for macOS, Windows, and Linux.

03 / DOCS

English instructions

Usage instructions and the release notes for that exact version.

04 / LEGAL

License and profile

The license text plus a machine-readable client profile for the release.

Requirement: JDK 21 or later to run CT. The Java runtime the game needs is downloaded by CT itself from Mojang's official runtime manifest. Release records, client profiles, and licenses live in versions/CT vX.Y.Z/ in the repository.
