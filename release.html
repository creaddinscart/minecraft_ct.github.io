Release profile

The machine-readable profile for this release is included in CT-Client-2.2.0.1.zip. It declares all Minecraft Java version IDs published by Mojang's official manifest, with the latest release selected by default.

Use the v2.2.0.1 update notes for interface and compatibility details.

Runtime and build

  • Run CT with Java 21 or later.
  • CT installs the Java runtime declared by the selected Minecraft version.
  • Current build artifact: target/ct-client-2.2.0.1.jar.
  • CT ZIPs do not include game files, official assets, third-party mods, or loader installers.

Versioning and records

Release directories use CT vMAJOR.MINOR.PATCH[.BUILD]. Keep the Minecraft version separate from CT's own version. Do not overwrite a published release record; create a new release directory for fixes and retain previous release artifacts for audit.

License status

The v2.2.0.1 release license identifies Creaddinscart Teams as rights holder and takes effect on 2026-10-02. It grants no rights to Minecraft, Mojang, Microsoft, Fabric, Sodium, their trademarks, or their assets. Do not distribute Minecraft files or third-party mods with CT.

The applicable local jurisdiction and rights-holder identity should be confirmed and reviewed by qualified counsel before external distribution. The release-specific license is included in the v2.2.0.1 desktop ZIP. See security and distribution notes.
