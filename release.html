Release portal / current release CT v4.2.0

Download CT.

Since v4.0.0 CT is modular: the main program is a bare module host, and every feature is a separate jar. Download CT-Main, download the modules you want, and drag them onto CT-Main-4.2.0.jar — it installs them all and opens with the new features. Running a module jar on its own installs just that module.

How the pieces fit together.

01 / HOST

CT-Main

The module host with the welcome window. Scans the modules folder on every start.

02 / MODULES

Module jars

Drop them into ~/.ct-client/modules or a modules folder next to CT-Main.jar.

03 / SOURCE

Open source

Every line browsable at code.html and in the source archive.

Requirement: JDK 21 or later to run CT. The Java runtime the game needs is downloaded by CT itself from Mojang's official runtime manifest.
