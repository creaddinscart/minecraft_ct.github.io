CT Client v2.2.0.1 / Desktop

Choose any Minecraft version.

CT loads all release, snapshot, and legacy IDs listed in Mojang's official manifest. Game files are fetched from Mojang and verified locally.

Requirements

  • JDK 21 or later to build and run CT.
  • Network access to piston-meta.mojang.com, launchermeta.mojang.com, and resources.download.minecraft.net for game installation.
  • Microsoft sign-in additionally uses login.microsoftonline.com, *.auth.xboxlive.com, and api.minecraftservices.com.
  • CT installs the Java runtime declared by the selected game version; the host Java is used only to run CT.

Download from this website

Download CT Client v2.2.0.1 (.zip) and extract the archive. The ZIP includes the GUI JAR and platform launch scripts.

macOS: run launch-macos.command. Windows: run launch-windows.bat. Linux: run launch-linux.sh. Java 21 or later is required to run CT.

Select and install a game version

On launch, CT loads Mojang's official version catalog. Select or enter any listed release, snapshot, or legacy version ID, then click Install / Verify and Launch. The selector defaults to the latest release. Sign in with Microsoft for online-mode servers, or choose an offline profile for local development and single-player use.

CT can start installed Fabric, Forge, and NeoForge profiles, but their installers must be run separately.

Fabric, Forge, and NeoForge

Install Fabric, Forge, or NeoForge with its own installer and select the same game directory configured in CT. If Fabric mod JARs are in mods/, CT automatically uses the sole installed Fabric profile matching the selected Minecraft version. If none matches, install Fabric Loader into that game directory; if several match, click Refresh versions and choose a profile explicitly. CT installs a profile's vanilla Minecraft parent version if needed, then hands off to the loader's own main class.

CT does not install or update external loaders. Mods are loaded by the selected loader and must match its Minecraft and loader versions; CT's native mod API is separate.

Microsoft sign-in setup

Configure an Azure public-client application with device code flow enabled and the XboxLive.signin and offline_access scopes. Add the client ID in CT settings or set CT_MICROSOFT_CLIENT_ID. The account must own Minecraft Java Edition.

CT opens a browser and displays a device code. Complete the sign-in there; CT then validates the Minecraft profile before launch.

Command line

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine [options]
OptionMeaningDefault
--version <id>Any ID in Mojang's official version manifest.Latest release
--game-dir <path>Game directory.Settings value, otherwise ~/.ct-client/game
--player <name>Offline profile, 3-16 letters, digits, or underscores.CTPlayer
--memory-max <mb>Maximum Java heap size in megabytes.Settings value
--verifyRe-check installed files against official SHA-1 values.Off
--install-onlyInstall and verify, then exit.Off
--dry-runPrint the launch command without starting Minecraft.Off
--helpPrint the option summary.-

CLI mode always uses an offline profile and has no Microsoft sign-in. It waits for Minecraft to exit and returns the game's exit code.

java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --install-only
    java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --player DevPlayer
    java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --dry-run
    java -cp target/ct-client-2.2.0.1.jar com.ct.client.CommandLine --version 1.20.4 --verify --install-only
