CT v3.0.0.1 / quick start

Get Started

CT Client is a single JAR and a self-contained game directory. Install the game, pick a version, and launch — the setup happens automatically on first launch.

Before you begin

Requirements

CT itself runs on your host Java. The Java runtime that Minecraft needs is downloaded by CT from Mojang's official runtime manifest.

01 / JAVA

JDK 21 or later

Required to build and to run the launcher. The build targets maven.compiler.release=21.

02 / NETWORK

Mojang hosts

piston-meta.mojang.com, launchermeta.mojang.com, and resources.download.minecraft.net for installation.

03 / ACCOUNT

Microsoft endpoints

login.live.com, login.microsoftonline.com, *.auth.xboxlive.com, and api.minecraftservices.com are needed only for Microsoft sign-in.

Three steps

From download to launch

Follow the steps in order. Launch performs the installation first if the game is not installed yet.

  1. 1

    Download or build CT

    The simplest path is the desktop ZIP from the release page. It contains the GUI JAR, platform launch scripts for macOS, Windows, and Linux, English instructions, and release notes. If you prefer to build from source, the Maven wrapper downloads Maven 3.9.16 on first use:

    ./mvnw package

    This produces target/ct-client-3.0.0.1.jar and also HTML/downloads/CT-Client-3.0.0.1.zip.

  2. 2

    Run the launcher

    Start the desktop launcher with your host Java:

    java -jar target/ct-client-3.0.0.1.jar

    The window shows the account state, the settings, the launcher console, and the Install/Verify and Launch actions. CT checks the local installation on startup and reports the result in the console.

  3. 3

    First launch installs the game

    You do not need a separate install step. Launch installs the game first if it is not installed yet: CT reads Mojang's official version manifest, downloads the client, every applicable library, the asset index, and all assets, verifies each file against the published SHA-1 and size, and installs the Java runtime component declared by the version metadata. If an install stops partway, run it again — verified files are kept, so it resumes.

  4. 4

    Sign in or use an offline profile

    Pick an account as described below, then launch. Game output streams to the launcher window and to <game directory>/logs/ct-client-launch.log.

Accounts

Microsoft sign-in

Online play requires a Microsoft account that owns Minecraft Java Edition. The built-in sign-in needs nothing else — no Azure application, no setup. A custom Azure client ID method remains available for users who registered their own application.

Press Sign in with Microsoft. With the default built-in method, the launcher immediately requests a device code, shows it, and opens microsoft.com/link — sign in there with the Microsoft account email and password, and CT completes the sign-in. Nothing needs to be configured first.

Custom Azure method: select Custom Azure client ID in the launcher's Settings panel and set the client ID there, or set it through the environment:

export CT_MICROSOFT_CLIENT_ID=your-azure-public-client-id

The application must be a public client with the device code flow enabled, allowed to use the XboxLive.signin and offline_access scopes. The environment variable overrides a stored microsoft.clientId value when it is set and not blank.

Both methods run the OAuth device code flow: CT shows a user code and a verification address, opens the browser, and polls for the token at the interval the service returns. The token is then exchanged through Xbox Live, XSTS, and the Minecraft services, and a profile check confirms the account owns Java Edition. Access tokens are never written to disk and are redacted from any echoed command; a Microsoft sign-in lasts for the current launcher session.

If sign-in fails with This Microsoft account has no Xbox profile, complete your Xbox profile setup once at xbox.com, then retry. See troubleshooting for the full list.

Offline profile

The offline profile needs no client ID and no network account. It cannot join online-mode servers.

No account

Offline profile

For development and single-player testing, use a local offline profile instead of Microsoft sign-in.

Select it in the desktop launcher with one click, or name it from the command line. Offline names are 3 to 16 characters of letters, numbers, and underscores; the profile derives a stable UUID from the name.

java -cp target/ct-client-3.0.0.1.jar com.ct.client.CommandLine --player DevPlayer

Command line mode always uses an offline profile — Microsoft sign-in is only available in the desktop launcher. Other useful flags:

java -cp target/ct-client-3.0.0.1.jar com.ct.client.CommandLine --install-only
java -cp target/ct-client-3.0.0.1.jar com.ct.client.CommandLine --dry-run
java -cp target/ct-client-3.0.0.1.jar com.ct.client.CommandLine --help

Limitation: offline profiles cannot join online-mode servers. The launcher does not retry the player/attributes or Realms endpoints, which reject offline profiles with HTTP 401.

--dry-run prints the exact launch command without starting the game, including the resolved official Java runtime path. The full option reference lives on the command line page; per-key preferences are documented under settings.
