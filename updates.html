What carries over

CT detects Fabric mod JARs by their root-level fabric.mod.json metadata and automatically launches the sole installed Fabric Loader profile matching the selected Minecraft version. Install Fabric Loader with its own installer into the same game directory configured in CT and place compatible Fabric mods such as Sodium in that directory's mods/ folder. Mojang game files are fetched from official Mojang endpoints by CT.

Scope and requirements

  • “All versions” means IDs listed by Mojang's official manifest; unsupported/unavailable server metadata cannot be launched.
  • Fabric Loader and all mod dependencies must be installed separately and match the chosen Minecraft version.
  • The static website distributes CT but cannot install software or launch a local game process inside a browser.
  • Mods execute Java code with the user's permissions and are not sandboxed.
