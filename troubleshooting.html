Support / CT v2.2.0.1

FAQ & troubleshooting.

Every CT error message states the cause and the action to take. If an install stops partway, run the same command again; verified files are kept, so the install resumes rather than restarting.

Current limitations

  • The desktop launcher persists the Microsoft client ID and the offline player name. The memory, resolution, game directory, and Java executable fields are read from settings.properties when the window opens, and the launch reads the settings file again, so edits to those four fields in the window do not change the next launch. Set them in settings.properties, or use the command line flags.
  • Command line mode has no Microsoft sign-in and no offline name persistence.
  • The launcher version passed to the game is 2.2.0.1, matching the Maven version in pom.xml.
  • Offline profiles cannot join online-mode servers, and the launcher does not retry the player/attributes or Realms endpoints, which reject offline profiles with HTTP 401.

Window edits to memory, resolution, game directory, and Java executable do not apply to the next launch. Set them in settings.properties or with the CLI flags.

Directory layout

~/.ct-client/
  settings.properties          Non-secret launcher settings
  game/
    versions/<id>/<id>.json    Verified official version metadata
    versions/<id>/<id>.jar     Verified client jar
    versions/<id>/natives/     Natives subdirectories referenced by the metadata
    libraries/                 Rule-matched libraries, including natives classifiers
    assets/indexes/            Asset index
    assets/objects/            Asset objects, stored under their SHA-1 prefix
    assets/log_configs/        Official log4j configuration
    runtimes/                  Official Java runtime, with the completion marker
    logs/ct-client-launch.log  Streamed game output, appended per launch

CT installs to ~/.ct-client; see settings for every key and default in settings.properties.

FAQ

01 / MODS

Can I use Forge or Fabric mods?

CT's native format is its own. See CT mods for CT Loader JARs and Fabric detection, and how installed Fabric, Forge, and NeoForge profiles are launched.

02 / OFFLINE

Can offline accounts join servers?

No. Online-mode servers reject offline profiles, and CT does not retry the player/attributes or Realms endpoints, which return HTTP 401 for them.

03 / SETTINGS

Where are settings stored?

In ~/.ct-client/settings.properties. It holds non-secret settings only; access tokens are never written to it.

04 / LAUNCH

Do window edits apply to launch?

No. Memory, resolution, game directory, and Java executable edits in the window do not apply to launch. Set them in settings.properties or with the CLI flags.
