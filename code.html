Build

Build it yourself

The build needs JDK 21 or later and nothing else — the Maven wrapper downloads the rest on first use.

unzip CT-Platform-4.3.0-src.zip
cd CT-Platform-4.3.0
./mvnw package

The build produces ct-main/target/CT-Main-<version>.jar and one jar per module in ct-module-*/target/. All unit tests run during the build; the same commands that verify a release are the ones you run at home.

To run your own build, point CT-Main at a modules folder:

mkdir modules
cp ct-module-*/target/ct-module-*.jar modules/
java -jar ct-main/target/CT-Main-<version>.jar --modules-dir modules
Manifest

Each module jar carries a ct.module.json: an id, a name, an entrypoint class, and the ids of the modules it requires.

CT's own code is open source; read the license page for the exact terms. CT downloads Minecraft files only from Mojang's official endpoints and never distributes game content.
