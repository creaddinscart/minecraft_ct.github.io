Track 1 / New users

Play Minecraft with CT, step by step.

This guide uses plain language only. No jargon, no source code, and no prior knowledge assumed. Follow the sections in order and you will be playing.

Step 1

What you need

Three things. Check them once and you are ready.

  • 1A computerWindows, macOS, or Linux. Any modern machine is fine.
  • 2Java (JDK 21 or newer)This is a free program that runs CT. If you do not have it yet, install JDK 21 or a newer version from any trusted provider.
  • 3InternetNeeded to download the game files. The first download is the big one, so a normal connection is enough.

The Java that runs Minecraft itself is downloaded automatically by CT. You only install the JDK for CT.

Step 2

Install CT

Download, unpack, and start. Three small actions.

  1. 1Download the ZIPGet CT-Client-2.2.0.1.zip from the Downloads page.
  2. 2Unzip itUnpack the file anywhere you like. Inside you will find the JAR file, launch scripts for Windows, macOS, and Linux, and English instructions.
  3. 3Start itOpen a terminal in the folder and run the command below. On Windows, macOS, and Linux you can also double-click the launch script for your platform.
java -jar CT-Client-2.2.0.1.jar

Prefer building it yourself? Run ./mvnw package in the project source. This produces the same JAR and the same ZIP.

./mvnw package
Step 3

Launch the game

One window, two fields, one button.

  1. 1Pick a versionUse the version box to choose the Minecraft version you want. Any version in Mojang's official list is there.
  2. 2Press LaunchThat is all. If the game is not installed yet, CT installs it first, automatically.

The very first launch takes a while, because CT downloads the game, its libraries, and all its files, and checks each one. Watch the progress bar and the console in the launcher window. Later launches are fast because everything is already on disk.

Step 4

Choose an account

There are two ways to play. Pick the one that matches what you want to do.

ONLINE PLAY

Microsoft account

Use this to play on online servers with the account you bought the game with. Press sign in in the launcher. A short code appears on screen. Open the website it shows you, type the code there, and confirm. That is the whole flow.

Sign-in needs a client ID set in the settings first. See how to set the client ID.

TESTING

Offline profile

Use this for single-player testing. One click, and a local profile is ready. No sign-in, no client ID, no waiting.

An offline profile cannot join online-mode servers. It is for trying things out, not for real online play.

Access tokens are never saved to disk. A Microsoft sign-in lasts for the current launcher session, and the offline profile is selected again with one click.

Step 5

Add mods in three steps

Mods are just files you place in one folder.

  1. 1Open the mods folderIt lives inside the game directory. Per-platform instructions, including how to reach the hidden folder, are on the mods page.
  2. 2Drop the files inCopy each trusted .jar file straight into that folder. No installer needed.
  3. 3Restart the gameClose the game, then launch again from CT. The mods load on startup.

Mods are executable code. Only use JAR files you trust, from sources you trust.

Step 6

Change RAM and window size

Two settings people ask about most: how much memory the game gets, and how big the window is.

RAM is the working memory the game may use. More RAM helps with heavy mod packs. The minimum is the smallest amount the game always gets, and the maximum is the most it may take.

Window size controls how many pixels wide and tall the game window opens. You can also leave it off and let the game decide.

Important: edit these in the settings file, not in the launcher window. The window fields for memory and resolution are read from ~/.ct-client/settings.properties when the window opens, and the launch reads the file again, so changing them in the window does not change the next launch. See why the window fields behave this way.

Open the file ~/.ct-client/settings.properties in any text editor and set the lines you need:

memory.minimumMb=2048
memory.maximumMb=4096
resolution.custom=true
resolution.width=854
resolution.height=480

Save the file and launch again. Numbers must be sensible: the maximum cannot be smaller than the minimum, and the resolution cannot be smaller than 320 by 240.

Step 7

Five common problems, five easy fixes

If something goes wrong, it is almost always one of these.

ProblemFix
The game does not start at allInstall Java 21 or newer, then try again. CT needs it to run.
The message Set your Microsoft application client ID appearsA client ID must be set before sign-in. Follow setting the client ID.
Microsoft sign-in failsThe account must own Minecraft Java Edition. If it does not, sign-in cannot complete. Use an offline profile for testing instead.
A download is interruptedPress install again. Verified files are kept, so the install resumes instead of restarting.
Mods do not loadEach mod JAR must be directly inside the mods folder of the game directory, then restart the game.

Still stuck? The troubleshooting page lists every known error with its cause and exact fix.
